## Use these docs with AI agents

The documentation is available to AI agents and tools as plain Markdown, from the same content as these pages:

- [`/llms.txt`](/llms.txt) lists every page with a short description.
- Add `.md` to any page URL to get its Markdown, for example [`/reference/configuration.md`](/reference/configuration.md).
- [`/llms-full.txt`](/llms-full.txt) contains every page in a single file.
- `https://docs.ymirapp.com/api/mcp` is a read-only [MCP](https://modelcontextprotocol.io) server with `list_pages`, `get_page` and `search` tools.

To connect an MCP client, add the server to its configuration:

```json title="MCP configuration"
{
  "mcpServers": {
    "ymir-docs": { "url": "https://docs.ymirapp.com/api/mcp" }
  }
}
```
